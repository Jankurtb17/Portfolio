# Jan Kurt's Portfolio (React + Vite + Tailwind CSS)

Personal developer portfolio for **Jan Kurt Bayaras**, a Web Developer specializing in React, Vue.js, Node.js, and Full-Stack Engineering.

## Features

- **About Me**: Introduction, personal profile photo, social links (LinkedIn, Facebook, Instagram), and CV access.
- **Professional Skills**: Visual proficiency bars and skill descriptions for web technologies (HTML, CSS, JavaScript, React, Vue.js, Python, Laravel, Tailwind CSS).
- **Projects**: Portfolio gallery featuring real-world projects such as the Task Application and Batanes Travel Website with project links.
- **Resume & Education / Experience**: Interactive accordions detailing educational background and engineering experience (JFE Techno Manila, Trend Micro, RBT Consulting).
- **Contact Me**: Interactive contact form with mailto integration and contact details (phone, email, Makati address).
- **Responsive Navigation Drawer**: Smooth scroll navigation with animated hamburger menu and backdrop drawer.
- **AOS Animations**: Scroll animations throughout the page.

## Tech Stack

- **React 19**
- **Vite**
- **TypeScript**
- **Tailwind CSS**
- **AOS (Animate On Scroll)**

## Development

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
